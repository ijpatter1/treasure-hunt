# Region Dossier — Washington DC / Mid-Atlantic

**Scope:** Smithsonian (Washington DC), Mount Vernon / northern Virginia,
Philadelphia (PA), Delaware, Pittsburgh / Carnegie (W-PA).
**Analyst role:** Deep analyst for the DC / Mid-Atlantic region.
**Sources read:** all seven graded triage batches
(`botg/ledger2/triage-01.md` … `triage-07.md`) plus raw units
`botg/ledger/raw/ch17.md`, `ch18.md` for full provenance context.

> Method note: I count only signals whose geographic implication actually lands
> in this region. Repeated mentions of the SAME underlying fact collapse to one

## 4. Case FOR vs. case AGAINST

### Case FOR (honest best argument)
- The book contains **two named, real Mid-Atlantic-tethered treasure items** —
  Washington's jelly glass (Mt Vernon/VA) and Carnegie's emerald (Pittsburgh/PA)
  — and JCB states item histories are part of the puzzle, so these are
  legitimate, non-zero pointers (graded MODERATE in triage).
- A third item (the Onassis brooch) adds a DC owner-biography thread, and the
  Coffer box's Smithsonian display puts DC on the page again — so DC/Mid-Atlantic
  is *mentioned* across multiple independent chapters (Ch3, Ch7, Ch10, Ch17,
  Ch18), more touchpoints than several rival regions.
- The Potomac corridor / Shenandoah and the Allegheny highlands DO contain
  genuine public-land, within-3-mi-of-road, terrain-satisfying sites if one
  follows the Washington theme inland.

### Case AGAINST (why it is likely illusory)
1. **No internal convergence.** The 2–3 pointers aim at 3 far-apart places
   (N-VA, W-PA, downtown DC). Convergence needs INDEPENDENT signals on the SAME
   region — absent here.
2. **All pointers are the weakest class (item / owner provenance).** Provenance
   names the object's past, not the hide. None is reinforced by an independent
   terrain riddle or by author biography.
3. **Biography points AWAY.** Author life-geography is NC + CA, zero
   Mid-Atlantic. Under the ruling, that is a counted strike against this region.
4. **Smithsonian collapses to a museum trope** → hide-ineligible urban campus →
   ~0.
5. **Named anchors are hide-ineligible.** Smithsonian (urban), Mount Vernon
   (paid private estate, not public land), downtown Pittsburgh — none satisfy
   "accessible public land, not buried, <=3 mi of a road, boots-on-the-ground in
   nature." To make the region work you must discard the very anchors that put
   it on the list, at which point it has no edge over NC/MA/CA.
6. **Discriminators that matter (granite, twin-peak vista, dark sky) fail at the
   named anchors** and are only met by going far west, where no independent
   signal points.
7. **Lone-association / Smithsonian-display bias:** several of these mentions are
   "the object lives in / is from X museum/estate" — the most generic possible
   provenance, the kind that fingers a region purely because famous Americana is
   curated there.

### Prior boots-on-ground / pin status
No BOTG or pin attempt has targeted the Mid-Atlantic. Project memory records the
only field effort as **Rocky Face Mountain, NC (FAILED)**, and the strongest
emergent leads (Bakersville/Mitchell, Hiddenite/Alexander, Chapel Hill,
Statesville) are all in NC. The Mid-Atlantic is therefore neither refuted nor
supported by fieldwork — it simply never rose to warrant a trip.

## 5. Honest convergence verdict

**THIN.**

DC/Mid-Atlantic rests on 2 (generously 3) **non-converging, provenance-only**
pointers — Washington's jelly glass (Mt Vernon), Carnegie's emerald
(Pittsburgh), and a weak Onassis-DC owner-biography thread — plus a Smithsonian
display mention that collapses to a hide-ineligible museum trope. There is **no
author-biography support** (author biography actively points to NC/CA), **no
internal convergence** (the pointers scatter ~250 mi apart), and the named
anchors fail both the hide-eligibility filter and the narrowing discriminators
(granite, twin-peak vista, dark sky). Generic terrain is satisfiable but
non-discriminating. This region is a thematic by-product of two famous-American
treasure items, not a place the evidence drives toward.

> Only path to upgrade: an independently-sourced, explicitly-named
> Shenandoah / Potomac-headwaters / Allegheny terrain signal that converges with
> MA1 or MA2 on a SINGLE hide-eligible public-land site. No such signal exists in
> the ledger; until one appears, hold at THIN.
