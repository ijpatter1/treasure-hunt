## Counter-Evidence

### Distance Issue

The author describes Hiddenite as "only some miles up the road" (Ch 4). Stone Mountain is approximately 50-60 miles away, which is significantly further than "miles up the road" suggests.

| Location | Distance from Childhood Home | Description Fit |
|----------|------------------------------|-----------------|
| Hiddenite | ~15 miles | "Miles up the road" ✓ |
| Stone Mountain | ~55 miles | NOT "miles up the road" ✗ |

This suggests that IF the treasure is in NC, a location closer to Hiddenite/Statesville might be a better fit for the "personal connection" angle.

### No Direct Mention

Stone Mountain State Park is never explicitly mentioned in the book. Unlike Hiddenite (mentioned by name in Ch 4), there is no direct textual connection to Stone Mountain.

## Conclusion

The author connection to Stone Mountain State Park is primarily **thematic** rather than **direct**:

**Supporting factors:**
- Same state (North Carolina)
- Same region (western NC mountains)
- Similar setting (woodland, mountain, nature)
- Childhood accessibility (day-trip distance)

**Against:**
- No direct mention in book
- Distance doesn't fit "miles up the road" description
- No known personal/family connection documented

**Assessment:** MODERATE connection. Stone Mountain fits the general profile of places the author would know from childhood, but lacks the direct textual connection that Hiddenite has. The hypothesis stands on poem/clue alignment rather than biographical evidence.
