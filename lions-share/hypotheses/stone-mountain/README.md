# Stone Mountain State Park Hypothesis

**Theory:** The Lion's Share treasure is hidden at Stone Mountain State Park, a 14,000-acre park featuring a 600-foot granite dome in Alleghany/Wilkes counties, North Carolina.

**Status:** Active (Initial Investigation)

**Created:** 2026-01-10
**Last Updated:** 2026-01-10

---

## Theory Statement

Stone Mountain State Park is a Tier 1 candidate location based on:
1. Strong "pike" (peaked geography) match - 600-foot granite dome dominates landscape
2. "Sat upon a rock" - massive granite dome summit is iconic sitting spot
3. Water features - 200-foot Stone Mountain Falls
4. North Carolina location - same state as author's childhood (though further from Hiddenite than Rocky Face)
