# Lion's Share Treasure Hunt — Wiki

A static, self-contained HTML wiki generated from the analysis of *There's Treasure Inside* by Jon Collins-Black. It cross-links every chapter's people, places, items, and themes to help surface geographic leads for the Lion's Share box.

## How to Open

Open `wiki/index.html` in any web browser (no server required — all pages are static HTML linked relatively):

```
open wiki/index.html
```

## Structure

- **25 chapter pages** — one HTML page each for the front matter, all 23 chapters, and the back matter (`front-matter.html`, `chapter-01.html` … `chapter-23.html`, `back-matter.html`).
- **5 hub pages** — `index.html` (home), `people.html`, `places.html`, `items.html`, `themes.html`. Each hub aggregates and cross-links entities across all chapters.
- **Shared stylesheet** — a single `wiki.css` styles every page.
