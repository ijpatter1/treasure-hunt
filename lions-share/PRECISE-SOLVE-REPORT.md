## Solve mechanism applied throughout

Verified poem (Stanza 3, `chapters/joys-serenade.md`): *"See how far to go. / Use will's straight edge, as the turning square or any arc / may align at a proper point."* — verified **lowercase** "will's" (NOT the name William; that capitalization trick was part of the NC contamination and is rejected here). Read literally, this is a **triangulation / sight-line** instruction: stand where bearings from named landmarks cross ("align at a proper point"). To run a real triangulation you need **two or more independently-named landmarks** the book/items actually point to. The recurring failure below is that none of the three leads supply a second independent named landmark — so there is nothing to cross a bearing *with*. A single feature cannot be triangulated; it can only be pointed *at*, which is precisely the lone-association trap.

Hide-pattern tests applied on each candidate:
- **Vista test (Ch.4, p.53):** prize near a distinctive overlook where a wider view opens, often *framed between two rock features*.
- **Behind-a-rock test (Ch.6, p.69):** box concealed behind/under a surface rock, not buried.
- **Convergence gate:** does an independent chapter/item thread *also* select this exact point (not just the region)? If only the poem's generic imagery fits → DESK-ONLY.
